# OSI and TCP
interactive visualizer that compares the OSI and TCP/IP network models

OSI vs TCP/IP Network Models Visualizer
Project Overview

This project is an interactive visualizer built in Jupyter Notebook that compares the OSI (Open Systems Interconnection) model and the TCP/IP (Transmission Control Protocol / Internet Protocol) model.

It provides both:

Static View – Displays the two networking models side-by-side.

Animated View – Shows moving arrows and transitions that illustrate how layers in the OSI model relate to layers in the TCP/IP model.

The goal is to help learners clearly understand how the two models map to each other and how network communication is structured.

Learning Objectives

After using this visualizer, users should be able to:

Identify all 7 OSI layers.

Identify all 4 TCP/IP layers.

Understand the functional similarities between the two models.

Visually see layer-to-layer relationships.

Recognize that TCP/IP combines several OSI layers into fewer layers.

Features
1. Static Comparison

Displays OSI and TCP/IP layers in colored blocks.

Side-by-side layout for quick comparison.

Clean and readable labels.

2. Animated Mapping

Smooth arrow animations.

Demonstrates which OSI layers correspond to which TCP/IP layers.

Repeating animation loop for continuous learning.

Helps visual learners grasp relationships faster.

3. Color-Coded Layers

Each layer has a distinct color to:

Improve readability.

Separate functions visually.

Reduce confusion between layers.
